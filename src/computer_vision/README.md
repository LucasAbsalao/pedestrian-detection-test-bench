# Computer Vision - Hardware in the Loop Evaluation System

This project implements an evaluation system with **Hardware in the Loop (HIL)** for testing detection systems. The concept is:

1. A video is displayed on a screen
2. The detection system (under test) watches the screen through a camera
3. Every time a person passes through danger zones in the video, the detection system should trigger an alarm sound
4. This system evaluates the detection system's performance by comparing its output against ground truth annotations

## Project Structure

```
src/computer_vision/
├── calibrate_alarm.py    # Alarm frequency calibration
├── generate_data.py      # Dataset generation with annotations and distortions
├── evaluate.py           # Evaluation of detection system against ground truth
├── config/               # Configuration files (alarm.yaml, parameters.yaml)
├── models/               # YOLO models (yolo26n.pt, yolo26l.pt, yolo26x.pt)
├── utils/                # Utility modules (audio_handler, draw, transformations)
└── scripts/              # Supporting scripts (zone_counter, video_augmentation, lines_prediction, draw_trapeze_points)
```

## Main Files

### 1. calibrate_alarm.py
**Purpose**: Calibrates the alarm frequency that the detection system emits.

- Records **10 seconds of audio** from the detection system's alarm
- Computes the spectrogram and finds the frequency with maximal amplitude over time
- Takes the **mode (most frequent value)** of the maximal amplitude frequencies during this interval
- This frequency is saved as the **alarm frequency** in `config/alarm.yaml` with a user-defined name
- Generates visualization plots (spectrogram, max/mean amplitude, frequency detection) for verification

### 2. generate_data.py
**Purpose**: Creates the evaluation dataset with ground truth annotations and distorted video versions.

- Uses a **YOLOv8 model** (default: `yolo26x.pt`, changeable via `--model` parameter) to detect people traversing danger zones
- Danger zones are defined by trapezoid points (marked via `draw_trapeze_points.py` and stored in `data/points.yaml`)
- Saves annotations in **YOLO format** to `/data/annotations/`
- Applies **video degradations/distortions** (via `video_augmentation.py`) to each original video
- Saves distorted videos to `/data/videos/distortions/`
- Generates a master YAML file (`data/{dataset_name}.yaml`) mapping all videos (original + distorted) to their annotations and zone points

### 3. evaluate.py
**Purpose**: Evaluates the detection system's performance using Hardware in the Loop.

- Loads the dataset YAML generated by `generate_data.py`
- Iterates through **all videos** in `/data/videos/` (including distortions)
- Uses `zone_counter.py` to:
  - Play each video on screen (simulating the HIL setup)
  - Run the detection system on the video
  - Compare detection system output against ground truth annotations
- Outputs evaluation metrics to a CSV file in `/evaluations/{evalutions/{eval_name}.csv`
- Visualizes detections with `--draw True` flag

## Data Flow

```
Original Videos (/data/videos/)
    │
    ├── generate_data.py ──► Annotations (/data/annotations/)
    │                           │
    │                           ├── Distorted Videos (/data/videos/distortions/)
    │                           │
    │                           └── dataset.yaml (maps videos ↔ annotations)
    │
    └── evaluate.py ──► Evaluation Results (/evaluations/*.csv)
                          (using ground truth from dataset.yaml)
```

## Usage

```bash
# 1. Calibrate alarm frequency (run once per alarm type)
python -m src.computer_vision.calibrate_alarm --name "my_alarm"

# 2. Generate dataset with annotations and distortions
python -m src.computer_vision.generate_data --name "my_dataset" --model "path/to/model.pt"

# 3. Evaluate detection system (HIL)
python -m src.computer_vision.evaluate --name "eval_run" --dataset "my_dataset"
```

## Configuration Files

- `config/alarm.yaml` - Stores calibrated alarm frequencies by name
- `config/parameters.yaml` - General system parameters
- `data/points.yaml` - Danger zone trapezoid points per video
